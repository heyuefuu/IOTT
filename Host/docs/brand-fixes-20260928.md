# 马扎克、哈斯、精雕接入修复（2026-09-28）

本次修改覆盖前端配置入口、驱动能力及可在本机复现的问题。未连接真实机床，不能代替现场验收。

## 已完成修改

- CNC 页面增加 MTConnect、HaasMdc、JingDiao；从品牌树新增和切换品牌均带出对应协议及默认端口 5000、9999、89。兄弟默认 MTConnect，牧野默认 FOCAS；现场仍可调整协议、端口和型号。
- 正式驱动注册补齐“哈斯（Haas）”“牧野（Makino）”别名，保持型号优先及通配规则。
- 修正种子库中的 3 台马扎克、2 台哈斯的协议和端口。种子仅用于空库初始化，不覆盖已保存的设备配置。
- Haas 兼容 `>Q104 IDLE`、`>MODE, (MEM)`、`>M30 #1, 553` 及宏变量响应，保留 Q500 复合状态和错误信息；宏布尔、整数、浮点值经过回归。
- MTConnect 支持在页面配置厂商写接口与明确的可写点位；浏览、导出和写入判定使用同一白名单。Token 仅随写请求发送，不发往标准采集端点。
- 精雕接入 SDK 宏变量写入，支持布尔、整数及浮点；拒绝非法地址、非有限值、类型越界、整数小数及不能无损传入 double 的大整数。其他点仍只读。
- 精雕上传从驱动经 IPC 传递目标目录、目标文件名；先设置 SDK 收件目录，再发送原文件名。临时目录隔离上传，同一会话的设置目录与发送受锁保护。
- 精雕 `Program.Files` 返回文件列表 JSON；目录读取失败返回 Bad。地址导出请求 JSON 时返回 JSON。
- 精雕目录通过 SDK 查询真实文件类型和文件大小，查询失败明确报错，不填造大小。
- CNC 页面增加点位导入入口，复用 CSV/JSON 导入流程，按 CNC/PLC 筛选设备；增加 CSV 模板下载，并保留失败文件及显示行错误。
- CNC 独立传输通道与传输管理页增加串口，支持 PortName、BaudRate、DataBits、Parity、StopBits 的保存、回填和校验。串口使用 localhost:0，不要求 TCP 端口；网关不会回退到 TCP 探测。

## MTConnect 写配置

`ExtendedProperties` 使用以下键，前端提供对应输入框：

| 配置项 | 含义 |
| --- | --- |
| `WriteEndpointUrl` | 厂商 HTTP(S) 写适配接口 |
| `WriteAddresses` | 精确 DataItem.id，区分大小写；逗号、分号或换行分隔 |
| `WriteBearerToken` | 可选写接口令牌 |

适配器收到包含 `Address`、`DataType`、`Value` 的 JSON POST。未配置时保持只读；只配置端点但未指定点位、或端点格式非法时明确拒绝。
